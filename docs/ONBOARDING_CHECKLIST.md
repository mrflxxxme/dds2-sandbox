## Важное про «зеркало»

- **Источник правды — origin (`vladbydaev37/dds2`), прод собирается из `origin/main`.**
  Свежий `git clone` = актуальный проект. Локальная WIP-мешанина с этой машины
  (14 worktree, savepoint-коммиты, локальный `dev` behind 192) им **не нужна** и не передаётся.
- Если у тебя есть незапушенная работа, которая нужна менеджерам (напр. loan/VTB/saby из памяти) —
  сначала запушь её в ветки на origin, иначе клон её не увидит.

## Модель совместной работы

- Оба пушат в `dev` напрямую (как Иван) → CI → merge в `main` → авто-деплой.
- Миграции — sequential, за голову `origin/dev`; две ветки-миграции одновременно не плодить
  (иначе две alembic-головы). Координируйте, кто делает миграцию.
- Ветки: `feat/` `fix/` `infra/` `refactor/` `test/`. После кода — `/review`, перед отправкой — `/verify`.
