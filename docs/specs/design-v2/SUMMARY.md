## Как исполнять

1. Прочитать `CLAUDE.md` → v1-CHARTER → этот CHARTER-V2 → STATUS → phase-spec активной волны.
2. Ветка от свежего `sandbox/main`, одна на волну; цикл фазы — v1 §4 (Scope → Implement → Verify → Review → Close).
3. Волны B и C — tripwire (`models/`, `migrations/`, `schemas/`): правит только lead, подпись архитектора ДО мержа.
4. Закрытие волны — строка в STATUS с датой, commit-sha и evidence; owned-решения — в DECISIONS-LOG.
5. PR в `sandbox/main`. В `origin` не пушится ничего (Р16 v1).
