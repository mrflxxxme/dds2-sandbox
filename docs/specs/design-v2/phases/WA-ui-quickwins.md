### 3. Строка фильтров над доской (Р21)

Новый `components/BoardFilters.tsx` — одна строка компактных контролов над колонками:
- селект «Исполнитель» с поиском (значения из карточек доски);
- селект «Тип работы» (`DESIGN_WORK_TYPE_LABEL`);
- переключатель статуса-вне-доски: «На доске» (дефолт) / «Отложенные (N)» / «Отменённые (N)» —
  счётчики берутся из `counts` ответа `/board`, как сейчас в кнопках;
- чекбокс «Только срочные»;
- поиск по названию/номеру.

Фильтрация клиентская, поверх уже загруженных колонок (Р10 — новых запросов не добавляем).
При выборе «Отложенные»/«Отменённые» вместо 6 колонок показывается плоский список этих задач
(данные — тем же `GET /design-tasks?status=`, что использовал overlay).
`HoldCancelledOverlay.tsx` удаляется, кнопки «⏸ Отложенные / ✖ Отменённые» из `page.tsx` — тоже.

Селект с поиском: если готового компонента в репо нет — простой `<input>`-фильтр внутри
выпадашки (референс-скрины заказчика), без новых зависимостей.

### 4. Общий `PeriodPicker` + рестайл календаря (Р22)

- Вынести `AdsPeriodPicker` в `src/components/PeriodPicker.tsx` без изменения поведения
  (два месяца рядом, пресеты Сегодня/Вчера/30 дней/3/6/12 месяцев, ручной ввод dd.mm.yyyy,

- `calendar/page.tsx` + `MonthGrid.tsx` — рестайл под референс: скругления ячеек, подсветка
  диапазона/сегодня, шапка дней недели строчными, приглушённые дни соседних месяцев.
  **Структура остаётся**: это календарь задач по `due_date` (Р7 v1), а не date-picker;
  `react-day-picker` для сетки задач не применять.

### 5. Тултипы-инструкции (Р24)

Единый `InfoTip` (или существующий паттерн тултипа рекламного модуля — сначала `grep`)
на все неочевидные элементы модуля:

| Место | Что объясняет |
|---|---|
| Заголовки 6 колонок доски | что означает статус и кто двигает задачу дальше |
| Кнопки переходов в деталке | что произойдёт и какие гварды (например, «нужна версия с файлами») |
| Метка «непросмотрено» (красная точка) | «новая заявка, ведущий ещё не открывал» |
| Бейдж «Срочно» | «пометка менеджера; порядок в колонке не меняет» |
| Чипы списка | по какому признаку срез |
| Метрики (пока в списке, потом на дашборде) | формула каждой из 6 метрик PRD §10 |

Тексты — в одном модуле-словаре (`lib/designHints.ts`), чтобы правились без вёрстки.
