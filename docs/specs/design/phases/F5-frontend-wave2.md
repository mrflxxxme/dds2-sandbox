## Работы

### Календарь (Р7)

CSS grid 7 колонок, месячная математика на `date-fns` (уже в deps; `startOfMonth/endOfMonth/eachDayOfInterval`, неделя с понедельника). Данные — `GET /calendar?month=YYYY-MM`. В ячейке дня ≤3 чипа задач (по `due_date`) + «+N»; сегодня — выделено. Переключатель раскраски (PRD §6): **по дизайнеру** (стабильная палитра по индексу assignee из `var(--color-*)`-набора) / **по статусу** (те же цвета, что колонки доски). Клик по дню — выезжающая панель со списком задач дня; клик по задаче — деталка. Стрелки месяц назад/вперёд.

### Загрузка

`GET /workload`: таблица по исполнителям — активные задачи, просрочено, в правках, ближайший срок; светофор по просрочке (0 зелёный / 1–2 жёлтый / 3+ красный); строка разворачивается в список задач исполнителя (`GET /design-tasks?assignee_user_id=`). Плюс строка «Не назначено» (задачи NEW/ASSIGNED без исполнителя).

### Сквозной экран

`GET /all-projects`: тот же табличный список, что в Ф3, + колонка «Проект»; без фильтра по проекту; переход по строке — в деталку соответствующего слага.

## AC

- **AC-1:** `npx tsc --noEmit` + `npx vitest run` — чисто (юнит на месячную сетку: январь-2027 начинается с пятницы, 31 день, недели с Пн).
- **AC-2:** Браузер: задача со сроком внутри месяца видна в правильной ячейке; переключатель раскраски меняет цвета чипов без перезагрузки.
- **AC-3:** Загрузка: счётчики строки исполнителя совпадают с фактом из списка (сценарий из 3 задач).
- **AC-4:** Сквозной экран пользователя с членством в одном проекте не показывает задач второго (проверка против бэкового AC-2 Ф2).
- **AC-5:** Все страницы — 4 состояния; пустой месяц/пустая команда дают внятный empty.
