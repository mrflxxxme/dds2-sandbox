# Как ставить задачу агенту — чтобы не жечь время и токены

Одна строка запомнить: **ЧТО · ГДЕ · КАК ПОЙМЁМ, ЧТО ГОТОВО**. Всё остальное — опционально.

## Формула

```
ЧТО:   одно конкретное действие/симптом (не «улучши», а «добавь поле X» / «падает 500 при Y»)
ГДЕ:   указатель — URL с портом, путь к файлу, ID сущности (заявка/поставка/nm_id), артикул
ГОТОВО: критерий приёмки — «в списке появилась колонка», «тест X зелёный», «500 больше нет»
ГРАНИЦЫ (если есть): что НЕ трогать, какой вариант выбрать при развилке
```

Хороший промпт из 2 строк лучше плохого из 20. Указатель (ГДЕ) — самое ценное слово в промпте:
без него агент тратит 10–20 минут на слепой поиск места.

## Примеры

**Баг — плохо:** `распределение опять не работает, ничего не изменилось`
**Баг — хорошо:** `/p/default/warehouse/assembly/distribute: после «Распределить» СЗФО получил 0.
Черновик dch-4412. Жёсткий рефреш делал, порт 3000. Ожидаю ~15% как в матрице.`

**Фича — плохо:** `сделай чтобы было видно сколько стоит логистика`
**Фича — хорошо:** `На Лист логиста добавь ₽/шт по категориям (pickup_cost / Σштук).
Готово = новая вкладка с таблицей и Excel. Кратность брать как в resolve_box_qty_by_warehouse.`

**«Ничего не изменилось»:** всегда добавляй три факта — был ли жёсткий рефреш, какой порт/стек,
та же ли сущность (ID). Половина таких случаев — кэш или не тот инстанс, а не код.

**Дизайн:** назови страницу-референс из нашего же приложения + что именно не так
(раскладка/цвета/плотность) + десктоп или мобилка. Иначе переделываем по 3 раза (прецедент: портал ФФ).

## Анти-паттерны (жгут токены впустую)

- **Несколько задач в одном промпте** — агент сделает все, но хуже и без фокуса. Одна задача = один промпт; пачку мелочей — нумерованным списком с пометкой «независимые».
- **«Изучи всё и скажи что не так»** без области — бесконечный аудит. Сужай: «изучи X в домене Y».
- **Пересказ того, что агент уже знает** — контекст сессии и память живы; не повторяй ТЗ из прошлого сообщения.
- **Расплывчатые слова без критерия**: «красиво», «правильно», «оптимально», «нормально» — агент угадывает твой вкус монетой.
- **Молчание про окружение при «не работает»** — прод или локалка? какой порт? когда началось?

## Что писать НЕ нужно

- Вежливость/преамбулы — не влияют, просто занимают токены.
- «Подумай хорошенько», «будь внимателен» — уже включено (effort high / ultracode).
- Технический план решения для мелкой задачи — достаточно ЧТО и ГДЕ, путь агент выберет сам.
  План стоит давать только когда есть жёсткое ограничение (схема БД, контракт API).

## Быстрый чек перед отправкой

```
□ Одна задача?  □ Есть указатель (URL/файл/ID)?  □ Понятно, как проверить готовность?
□ Для бага: что видишь / что ожидал / окружение?
```

Хук `[ТЗ-ГЕЙТ]` (`scripts/hooks/prompt_quality_check.py`) автоматически ловит расплывчатые
промпты и заставляет агента сначала задать 1–3 вопроса — но лучше, когда он молчит.
