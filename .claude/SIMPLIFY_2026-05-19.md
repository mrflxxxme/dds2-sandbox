# Agent setup simplify — 2026-05-19

> Резка ~60% правил/ceremony при сохранении iron rules. Источник: официальный Anthropic best-practices guide (code.claude.com/docs/en/best-practices) и HumanLayer "Writing a good CLAUDE.md" (нояб. 2025).

## Что изменилось

### CLAUDE.md
- 123 → 60 строк (Anthropic рекомендует <300, HumanLayer ~60).
- Убрано: дублирование Iron rules, развёрнутая навигация, разделы CI/Деплой/Среды (детали в `docs/_archive/` после optional move).
- Добавлены `@`-imports для progressive disclosure (lead_agent_v2.md, learnings.md, DOMAIN_INDEX.md, MEMORY.md, docs/_archive/).

### Hooks
- `prewarm-spawn.sh` → no-op (`exit 0`). Спекулятивный спавн на каждом промпте >30 символов тратил compute без выгоды.
- `prompt-team-detect.sh` → slim: только `[DOCS]` reminder + `/compact` counter. Убрана directive-injection (PARALLELISM/MIGRATION/TRIVIAL), вызов prewarm-spawn, git diff анализ. Lead-agent сам решает по тексту запроса.
- `teammate_idle_check.sh` → slim: только iron rules + worktree abs-path leak. Убран `check_conventions.sh` (heavy, дублирует pre-push).

### Не трогали (работает корректно, оставить как есть)
- `post_edit_check.py` — smart iron-rule checker, 135 строк Python, не блокирует.
- `pre_tool_check.sh` — блок `.env` / `--no-verify`.
- `pre-push` — тесты + audit перед push.
- `session_start.sh` — auto-context (commits, branch sync, uncommitted, pending /learn).
- `post_stop_check.sh`, `post_edit_check.sh`, `post-commit-*` — оставлены.
- `.claude/settings.json` — без изменений; новые slim хуки backward-compatible.

## Optional follow-up (по желанию, не критично)

Эти файлы больше не auto-load (нет ссылки из slim CLAUDE.md), но физически лежат на диске. При желании вычистить:

```bash
mkdir -p docs/_archive
git mv AGENTS.md ARCHITECTURE.md BUSINESS_RULES.md CONVENTIONS.md PLAYBOOK.md REVIEW.md docs/_archive/

mkdir -p .claude/commands/_archive
# Оставить активными: smoke, verify, migration, hotfix, plan, status, review, build-fix, learn
# Архив: codemod, docs, new-endpoint, new-page, pause, resume, rollback, spec, tdd
for cmd in codemod docs new-endpoint new-page pause resume rollback spec tdd; do
    git mv ".claude/commands/$cmd.md" ".claude/commands/_archive/$cmd.md"
done

mkdir -p .claude/agents/_archive
# Оставить активным: code-reviewer
for agent in api-designer build-error-resolver database-reviewer performance-optimizer planner security-reviewer tdd-guide; do
    git mv ".claude/agents/$agent.md" ".claude/agents/_archive/$agent.md"
done
```

## Что должно ускориться

1. **Старт сессии** — Claude грузит ~60 строк CLAUDE.md вместо ~123 + потенциальное auto-pull AGENTS.md/agent_workflow.md (~270 строк). Меньше токенов, меньше «inструкций для отслеживания» (HumanLayer: модель надёжно следует 150-200 инструкциям, у тебя сейчас гораздо больше).
2. **Каждый промпт** — нет lokuga prewarm-spawn (несколько секунд + tokens), нет directive injection.
3. **Лид-agent роутинг** — slim CLAUDE.md рекомендует «действуй сразу для мелочи / бага», без сложной таблицы skills. Меньше токенов на решение «что вызвать».
4. **Teammate idle** — быстрее (без `check_conventions.sh`).

## Что НЕ должно сломаться

- Любая команда `/smoke`, `/verify`, `/migration`, `/hotfix`, `/plan` — работает (файлы на месте).
- Iron rules enforcement (`post_edit_check.py`) — без изменений.
- pre-commit / pre-push — без изменений.
- CI / branch protection — без изменений.
- WB sync, sync-prod, миграции — без изменений (только docs/правила тронуты).
