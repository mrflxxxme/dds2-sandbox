# /bug — багфикс с чекпоинтом направления

Лёгкая полоса для бага, у которого **место примерно понятно**. Смысл — не дать минутному фиксу превратиться в часы: сначала дёшево подтвердить направление, потом править. Отличие от соседей:
- `/autofix` — автономный луп до зелёного (сам пишет репро, не спрашивает). `/bug` — один чекпоинт ПЕРЕД правкой, ты подтверждаешь направление.
- `/build-fix` — чинит уже падающую сборку. `debugger` (агент) — глубокая отладка в отдельном контексте. `/bug` — быстрый фикс в основном контексте.

**Баг:** $ARGUMENTS

## Шаг 0 — разобрать вход на ГДЕ / ЧТО / КАК
- **ГДЕ** — URL с портом, файл, ID сущности. Нет ГДЕ и место НЕ следует однозначно из сессии → **один** вопрос через `AskUserQuestion` («на какой странице/эндпоинте? ID сущности?»), не начинай слепой поиск. Если ГДЕ ясно из контекста — не спрашивай.
- **ЧТО** — «вижу X, жду Y» с конкретным числом/кейсом. Размыто («неправильно», «криво») → уточни эталон одним вопросом.
- **КАК** — по умолчанию **минимальный фикс, без расширения scope**. Явное «копай глубоко» / «может быть доменное» → разрешён шире.

## Шаг 1 — ЧЕКПОИНТ (ядро скила)
Перед первой правкой выведи **ровно три строки** и **жди `ok`** (не редактируй):
```
Файл:      <path:line — где корень>
Гипотеза:  <одна строка: почему ломается>
Проверка:  <как подтвержу фикс: репро-тест / curl / конкретный кейс>
```
Это ловит неверное направление за 60 сек вместо двух часов раскопок. **Пропусти чекпоинт только если фикс тривиально-очевиден** (опечатка, off-by-one, явный null-guard) — тогда сразу правь и покажи диф.

## Шаг 2 — различить класс бага
Если по ходу вскрылось, что это **доменная семантика** (WB прячет выручку через транзитный счёт, брак в резерве, COGS по месяцу vs дням — класс из `.claude/rules/learnings.md`), а не механика — **скажи об этом явно** и переключись в режим расследования: часы тут неустранимы, это цена открытия, а не плохой фикс. Не выдавай наспех «минимальный фикс» поверх непонятой семантики.

## Шаг 3 — фикс корня + проверка
- Чини **корень**, не симптом. Соблюдай iron rules (project_id, is_deleted, soft_delete, utcnow, Numeric, :param-binding, invalidate_cache, rate_limit_write).
- Проверь ровно тем, что заявил в «Проверка». Меняешь `backend/services|models` → mypy; фронт → tsc в one-off контейнере (node на хосте НЕТ).
- Изменение задело конвенции/паттерн, который стоит запомнить → короткая заметка в `learnings.md` (как база якорей на будущее).

## Стоп
Останавливаюсь на зелёном репро + непобитых соседях. **НЕ пушу** (push — только по явному запросу). Если фикс вышел за 3 файла или вскрылась цепочка — предложи перейти в `/autofix` (автономно до зелёного) или `/feature` (если это уже не баг).
