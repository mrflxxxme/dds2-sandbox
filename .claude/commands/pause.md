---
name: pause
description: Сохранить прогресс текущей задачи для продолжения в новой сессии.
---

Сохрани текущий прогресс задачи:

1. Определи текущее состояние:
   - Какая задача выполнялась
   - Какие файлы изменены (git diff --name-only)
   - Какие шаги завершены
   - Какие шаги остались

2. Запиши в файл `.claude/plans/paused-task.md`:
   ```markdown
   # Paused Task

   ## Задача
   [описание текущей задачи]

   ## Выполнено
   - [список завершённых шагов с файлами]

   ## Осталось
   - [список оставшихся шагов]

   ## Изменённые файлы
   [вывод git diff --name-only]

   ## Текущий worktree
   [путь к worktree если используется]

   ## Контекст
   [важные детали для продолжения: ветка, незакоммиченные изменения, зависимости между шагами]
   ```

3. Выведи:
   ```
   PAUSED: Прогресс сохранён в .claude/plans/paused-task.md
   Для продолжения в новой сессии: /resume
   ```
