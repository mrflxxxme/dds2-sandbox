# Build Fix — DDS2

Инкрементальное исправление ошибок сборки и тестов.

## Шаг 1: Определить систему сборки

| Компонент | Команда |
|-----------|---------|
| Backend тесты | `docker compose exec backend pytest tests/ -x --tb=short` |
| Конвенции | `bash scripts/check_conventions.sh` |
| Docker build | `docker compose build backend` |
| Frontend build | `cd frontend-react && npm run build` |

## Шаг 2: Разобрать и сгруппировать ошибки

1. Запустить команду, захватить вывод
2. Сгруппировать ошибки по файлам
3. Сортировать по зависимостям (сначала imports/types, потом логика)
4. Посчитать общее количество для трекинга прогресса

## Шаг 3: Цикл фиксов (по одной ошибке)

Для каждой ошибки:
1. **Прочитать файл** — контекст вокруг ошибки (10 строк)
2. **Диагностировать** — корневая причина
3. **Минимальный фикс** — наименьшее изменение
4. **Перезапустить** — проверить что ошибка ушла
5. **Следующая** — к оставшимся ошибкам

## Шаг 4: Guardrails

Остановиться и спросить юзера если:
- Фикс создаёт БОЛЬШЕ ошибок
- Та же ошибка после 3 попыток
- Нужны архитектурные изменения
- Ошибки из-за отсутствующих зависимостей

## Шаг 5: Итог

```
Исправлено: X ошибок
Осталось: Y ошибок
Новых ошибок: 0
```

Чинить по одной ошибке. Минимальные diff-ы. Не рефакторить.
