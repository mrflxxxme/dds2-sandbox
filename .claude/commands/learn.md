# /learn — Рефлексия после коммита(ов) DDS2

## Когда использовать
- После завершения фичи / бага / рефакторинга
- Автотриггер: Stop hook сообщает «N pending коммитов для /learn»
- Источник коммитов: `.claude/.pending-learn.log` (пишет post-commit hook)

## Процесс

### Шаг 1: Собери pending коммиты
Прочитай `.claude/.pending-learn.log`. Если файла нет или он пустой — спроси у пользователя за какой период анализировать, или возьми последние 3 коммита (`git log --oneline -3`).

Для каждого коммита из лога:
- `git show --stat <hash>` — список изменённых файлов
- `git show <hash> -- <файлы интереса>` — для конкретных диффов

### Шаг 2: Извлеки уроки (4 категории)

**2a. Новый антипаттерн** — если в diff видно проблему которая повторялась раньше:
- Добавь check в `scripts/check_conventions.sh`
- Запиши в `.claude/rules/learnings.md` (секция «Антипаттерны (не повторять)»)

**2b. Новый паттерн** — если решение элегантное и переиспользуемое:
- Если повторяется 3+ раза в репо → создай template в `.claude/templates/`
- Запиши в `.claude/rules/learnings.md` (секция «Паттерны которые работают»)

**2c. Исправлен баг из known_bugs** — если коммит содержит «fix:»:
- Найди связанный баг в `memory/project_known_bugs.md`
- Перенеси в секцию «Исправленные» с номером коммита и датой

**2d. Новый баг / технический долг** — если в коде увидел `TODO`, `FIXME`, `HACK` или явный workaround:
- Добавь в `memory/project_known_bugs.md` (секция «Актуальные»)

### Шаг 3: Обнови memory если есть feedback
Если в коммите видна:
- Корректировка поведения (был баг от агента) → новый `feedback_*.md`
- Подтверждение нестандартного решения → дополнить существующий feedback
- Новый workflow-паттерн → дополнить `feedback_workflow.md`

### Шаг 4: Документация
Запусти логику `/docs` (либо вызови сам skill, либо повтори шаги 2-3 из `.claude/commands/docs.md`).

### Шаг 5: Очисти pending-log
После обработки:
```bash
> .claude/.pending-learn.log
```

### Шаг 6: Отчёт
Краткая таблица:

```
| Категория | Что добавлено | Файл |
|-----------|---------------|------|
| Антипаттерн | except Exception без CancelledError | check_conventions.sh, learnings.md |
| Исправлен баг | P31 cache invalidation | project_known_bugs.md |
| Документация | DOMAIN_WB.md — новый sync_log пункт | DOMAIN_WB.md |
```

## Правила
- НЕ создавай файлы которых не было — только дополняй существующие (templates — исключение)
- НЕ дублируй уроки — сначала прочитай existing learnings/feedback
- Минимальные правки — только реальные изменения, не вода
- Если ничего нового не нашёл за коммит — так и напиши «No learnings extracted», очисти pending-log
- НИКОГДА не делай коммит автоматически — финальное решение за пользователем
