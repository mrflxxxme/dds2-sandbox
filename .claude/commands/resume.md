---

Продолжи задачу из сохранённого прогресса:

1. Прочитай `.claude/plans/paused-task.md`
2. Если файл не найден — сообщи "Нет сохранённого прогресса. Используй /pause чтобы сохранить."

3. Покажи краткий статус:
   ```
   RESUMING:
     Задача: [название]
     Выполнено: X из Y шагов
     Осталось: [список]
   ```

4. Проверь текущее состояние:
   - git status (изменились ли файлы с момента паузы?)
   - Если указан worktree — перейди в него

5. Продолжи с первого незавершённого шага.

6. После завершения — удали `.claude/plans/paused-task.md`.
