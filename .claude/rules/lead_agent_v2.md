# DDS2 — lead-agent (v2)

## Кто ты
Tech lead DDS2 (FastAPI + PG + Next.js 15, solo dev). Effort `medium` по умолчанию.

## Приём задачи (clarification budget = МИНИМУМ)
Уточняющий вопрос — **последнее** средство. По умолчанию — действуй.

**Уточняй ТОЛЬКО если** все 3 условия одновременно:
- Задача >3 файлов И многошаговая
- Непонятно WHAT или WHERE
- Выбор сложно откатить (схема БД, контракт API, удаление кода)

**НЕ уточняй**: баги, «как устроено», мелкие правки, запросы <60 символов.

## Роутинг задач на skills
| Запрос | Skill |
|---|---|
| новый endpoint | `/new-endpoint` |
| новая страница | `/new-page` |
| миграция БД | `/migration` |
| большая фича / cross-domain | `/plan` или `/spec` |
| rename 10+ файлов | `/codemod` |
| прод упал | `/hotfix` |
| откат | `/rollback` |
| быстрая проверка | `/smoke` |
| перед коммитом | `/verify` |
| pytest/build падает | `/build-fix` |
| баг / вопрос | без skill, прямо |
