# DDS — Бизнес-правила

> Описание бизнес-логики системы управленческого учёта

## 1. Транзакции и импорт

- **Дедупликация**: повторный импорт той же выписки не создаёт дублей (ON CONFLICT по hash)
- **Автокатегоризация**: транзакции категоризуются по ИНН/имени контрагента → `counterparty_categories`
- **INBOX**: нераспознанные транзакции попадают в INBOX для ручной разноски
- **Приоритет категоризации**: `overrides` (по txn_id) → `counterparty_categories` (по cp_key) → UNASSIGNED

## 2. Типы транзакций

| Тип | Описание | Влияет на ДДС |
|-----|----------|:---:|
| REGULAR | Обычные платежи | ✅ |
| FX | Конвертация валют | ❌ |
| INTERNAL | Внутренние переводы | ❌ |

## 3. Планирование

- **Заказы (PlanOrders)**: планируемые поставки товаров (ВЭД)
- **Платежи (PlanPayments)**: плановые расходы и доходы
- **Привязка факта**: реальные транзакции привязываются к плановым платежам через `fact_links`
- **Статусы платежа**: `planned` → `partial` → `paid`

## 4. Себестоимость

- **Заказы (CostOrders)**: поставки товаров с таможенным оформлением
- **Номенклатура**: товары привязаны к заказам, с весом, объёмом, ценой
- **Пошлины (DutyRules)**: правила расчёта по категориям товаров
- **Таможня**: ДТ номера, распределение таможенных платежей по товарам

## 5. Воронка продаж (WB)

- **Источник данных**: WB Analytics API (воронка) + WB Adv API (реклама)
- **Синхронизация**: посуточно, с retry для 429 (rate limit) и коммитом по дням
- **Агрегация по умолчанию**: без фильтов — данные группируются по дням (SUM)
- **Детализация**: при выборе бренда/артикула — данные по товарам
- **Метрики воронки**: переходы → корзины → заказы → сумма → выручка
- **Метрики рекламы**: расходы, просмотры, клики, CTR, CPC, CPM
- **Себестоимость**: берётся из последнего заказа или ручного переопределения
- **Налог**: процент от суммы заказов (настраивается в проекте, по умолчанию 6%)
- **Процент выкупа**: рассчитывается из данных воронки (заказы / корзины)

## 6. Интеграции с Wildberries

- **API-ключи**: хранятся зашифрованными в `wb_api_keys`
- **Типы ключей**: `analytics` (для воронки) и `adv` (для рекламы)
- **Rate Limiting**: обработка 429 с exponential backoff (30с, 3 попытки)
- **Частичные данные**: при ошибке — сохранять уже загруженные дни

## 7. Мультитенантность

- Каждый пользователь может создавать проекты
- Все данные привязаны к `project_id`
- Переключение проектов через UI
- Команда: приглашение пользователей в проект через email
