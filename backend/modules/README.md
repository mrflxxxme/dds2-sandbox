# Backend Modules

Модульная структура для масштабирования backend.

## Принцип

Каждый модуль — самодостаточный пакет с собственным router, service, schemas.  
Модули регистрируются в `main.py` через `include_router`.

## Структура модуля

```
backend/modules/<module_name>/
├── __init__.py
├── router.py      # FastAPI роутер
├── service.py     # Бизнес-логика
├── schemas.py     # Pydantic schemas (если отличаются от общих)
└── README.md      # Описание модуля
```

## Миграция

Существующие роутеры (`backend/routers/`) остаются как есть.  
Новые фичи создаются в `backend/modules/`.  
Постепенная миграция: перенос по одному модулю за итерацию.
